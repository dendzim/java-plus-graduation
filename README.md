# Explore With Me Plus

Приложение для размещения и поиска событий.
Используется микросервисная архитектура.

## Инфраструктура проекта

Используется Spring Cloud.

Сборка осуществляется при помощи Apache Maven

БД - Postgres

- **Discovery Server** (Eureka) — обнаружение и регистрация сервисов
- **Config Server** — централизованное хранение конфигураций
- **Gateway Server** — единая точка входа, маршрутизация запросов

## Общие модули проекта

- **interaction-api** — общие DTO и Feign-клиенты для взаимодействия между сервисами а также исключения и утилитарные классы


## Микросервисы Core модуля

| Сервис              | Назначение                           |
|---------------------|--------------------------------------|
| **event-service**   | События, категории, подборки событий |
| **user-service**    | Пользователи                         |
| **request-service** | Запросы на участие в событиях        |
| **rating-service**  | Оценки и рейтинг событий             |
| **stats-service**   | Сбор статистики просмотров событий   |

## Взаимодействие

Взаимодействие между модулями реализовано при помощи Feign клиентов.

## Микросервисы Stats модуля (Рекомендательный сервис)

Рекомендательная система состоит из трёх микросервисов: Collector, Aggregator и Analyzer. Каждый из них выполняет уникальную задачу по обработке данных и построению рекомендаций.

| Сервис           | Назначение                                                                                                      |
|------------------|-----------------------------------------------------------------------------------------------------------------|
| **aggregator**   | Выполняет анализ данных о действиях пользователей, рассчитывает ключевые метрики и сохраняет результаты в Kafka |
| **analyzer**     | Предоставляет рекомендации мероприятий пользователям                                                            |
| **collector**    | Принимает информацию о действиях пользователей по gRPC и передавать её в Kafka-топик в формате Avro             |
| **stats-client** | gRPC-клиенты к сервисам Collector и Analyzer                                                                                       |

Взаимодействие между сервисами происходит через Apache Kafka
